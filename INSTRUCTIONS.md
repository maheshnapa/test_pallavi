# Run instructions (this machine)

Practical "how do I actually run this" steps for this checkout. For protocol/architecture
explanation see `docs/ARCHITECTURE.md`; for the full cloud account setup see
`docs/CLOUD_SETUP.md`. This file only covers commands.

## Already done on this machine

- `python@3.12` and `portaudio` installed via Homebrew (system `python3` was 3.9.6, too old).
- `.venv/` created and `requirements-cloud.txt` installed (`livekit`, `livekit-api`,
  `sounddevice`, `google-cloud-dialogflow-cx`).
- `livekit-cli` (`lk`) installed for a standalone LiveKit connectivity check.
- `.env` created by `python -m ivr_poc init` — local secrets are already filled in.

All commands below assume you're in the repo root with `.venv` active, or just call
`.venv/bin/python` directly without activating.

## 1. Local demo — no `.env`, no keys, no network

```bash
.venv/bin/python -m ivr_poc demo
```
Runs 12 scenarios against an in-process fulfillment + specialist. Expect `12/12 checks passed`.

## 2. Local persistent services + interactive chat

```bash
# Terminal 1
.venv/bin/python -m ivr_poc serve

# Terminal 2
.venv/bin/python -m ivr_poc doctor
.venv/bin/python -m ivr_poc chat
```
Try: `check ORD-1001`, `check ORD-2001`, `east`, `quit`.

## 3. LiveKit connectivity check — needs your LiveKit keys only

Fill in `.env`:
```dotenv
LIVEKIT_URL=wss://your-project.livekit.cloud
LIVEKIT_API_KEY=your-key
LIVEKIT_API_SECRET=your-secret
```
Then, without touching Dialogflow CX at all:
```bash
lk room join --url "$LIVEKIT_URL" --api-key "$LIVEKIT_API_KEY" \
  --api-secret "$LIVEKIT_API_SECRET" --identity smoke-test a2a-ivr-demo
```
A clean connect/leave confirms the keys and room are reachable. This does not run any of this
project's code — it only isolates whether the LiveKit side works before wiring up CX.

## 4. Full real voice pipeline — needs LiveKit + Dialogflow CX + a webhook tunnel

Also requires `CX_PROJECT_ID`, `CX_AGENT_ID`, Google ADC login, and an HTTPS tunnel (e.g. ngrok)
to your local `serve` process. Follow `docs/CLOUD_SETUP.md` in order, then:
```bash
# Terminal 1: .venv/bin/python -m ivr_poc serve
# Terminal 2: ngrok http http://127.0.0.1:8000   (configure the CX webhook with this URL)
# Terminal 3
.venv/bin/python -m ivr_poc voice
# Terminal 4
.venv/bin/python -m ivr_poc microphone
```

## Env var quick reference

| Needed for | Variables |
|---|---|
| Anything (`demo`, `serve`, `chat`) | already generated by `ivr_poc init`: `A2A_BEARER_TOKEN`, `CX_WEBHOOK_TOKEN`, ports/timeouts |
| LiveKit connectivity check (§3) | `LIVEKIT_URL`, `LIVEKIT_API_KEY`, `LIVEKIT_API_SECRET` |
| Full voice pipeline (§4) | above, plus `CX_PROJECT_ID`, `CX_AGENT_ID`, `CX_LOCATION`, Google ADC login |

Full variable list and defaults are in `.env.example`.
